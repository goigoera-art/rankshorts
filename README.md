# RankShorts — конструктор вертикальных рейтинговых видео

Сайт собирает ролики 9:16 (TikTok / Shorts / Reels) в стиле «Ranking Best … Moments»:
заголовок сверху, список мест сбоку, подпись текущего клипа у его номера.
Всё работает в браузере (Canvas + MediaRecorder), без установки Node/Python/ffmpeg.

## Запуск

**Вариант 1 (рекомендуется):** дважды щёлкнуть `start.cmd`. Запустится локальный сервер
`http://localhost:8787/` (PowerShell, без установки) и откроется браузер.

**Вариант 2:** открыть `public/index.html` напрямую. Всё, кроме импорта по ссылке, работает так же.

**Импорт по ссылке (TikTok, YouTube Shorts и др.)** нужен yt-dlp:
```
winget install yt-dlp
```
или положите `yt-dlp.exe` в папку `tools/`. После этого перезапустите `start.cmd`.
Используйте только ролики, на которые у вас есть права.

Браузер: свежий Chrome или Edge (с версии 126 экспорт сразу идёт в MP4). Firefox тоже работает, но экспорт будет в WebM.

## Ссылки TikTok: что поддерживается и что нет
Принимаются ссылки `…/@автор/video/ID` (в том числе с `?is_from_webapp=…`), `vm.tiktok.com/…`, `vt.tiktok.com/…`,
`tiktok.com/t/…`, `…/v/ID.html`, `…/embed/v2/ID`, `…/share/video/ID`. Короткие ссылки и редиректы раскрываются сервером.

Скачивание **не гарантировано**: TikTok может ответить проверкой «Please wait» (защита от программ), ролик может быть
приватным, удалённым или ограниченным по региону/возрасту. В этих случаях сайт показывает причину и предлагает
«Повторить» (если имеет смысл) или «Загрузить файл с устройства». Проверку TikTok программа не обходит: после
блокировки она делает паузу ~45 с. Если блокировка держится, установите yt-dlp (`winget install yt-dlp`) или загрузите файл.

## Как ведут себя ссылки по платформам
| Платформа | Что видно сразу | Можно редактировать и экспортировать |
|---|---|---|
| TikTok | официальный плеер TikTok | только если удалось скачать файл (один запрос; при «Please wait» — стоп, кнопка «Повторить», загрузка файла) |
| Instagram Reels | официальный плеер Instagram | только после загрузки файла с устройства (или yt-dlp) |
| YouTube Shorts | официальный плеер YouTube | только после загрузки файла с устройства (или yt-dlp) |

Клип «только ссылка» помечен в очереди и **не попадает в экспорт**. Загрузка файла («Загрузить файл с устройства»)
превращает этот же клип в обычный: подпись и место сохраняются. Программа не обходит «Please wait», CAPTCHA и
авторизацию и никогда не повторяет заблокированный запрос сама.

## Файлы
- `tiktok.ps1` — встроенный загрузчик TikTok (разбор ссылок, редиректы, cookie-сессия, паузы, проверка файла)
- `public/index.html`, `styles.css` — интерфейс
- `public/app.js` — редактор: клипы, места, очередь, дизайн, экспорт
- `public/render.js` — сборка кадра (видео, заголовок, список, подпись)
- `public/watermark.js` — поиск и удаление водяного знака
- `public/engine.js` — последовательное воспроизведение клипов на canvas (предпросмотр и запись)
- `public/util.js` — хранилище IndexedDB и вспомогательные функции
- `serve.ps1`, `start.cmd` — локальный сервер и импорт по ссылке через yt-dlp

## Телефон (GitHub Pages)
Сайт опубликован статически из папки `public` (ветка `gh-pages`), поэтому открывается по обычной ссылке и на телефоне.
Если на этом же компьютере запущен `start.cmd`, опубликованный сайт сам подключается к нему (`localhost:8787`) и скачивание
работает и там; сервер принимает запросы только от localhost и от этого сайта. Без `start.cmd` скачивания по ссылке нет: загружайте видеофайлы с телефона, ссылки открываются во встроенных плеерах.
Проект хранится в браузере телефона и не связан с компьютером. Обновить сайт после правок: `publish.cmd`.
